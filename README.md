# IPOverlay




> Windows桌面悬浮IP显示工具，半透明悬浮窗常驻桌面，实时展示内网IP、公网出口IP，驻留系统托盘后台运行。

## ✨ 功能特性
- 🖥️ **桌面悬浮窗**：无边框置顶半透明悬浮窗口，支持鼠标拖拽移动，不抢占输入焦点
- 📡 **公网IP多接口轮询**：内置多套公网IP查询URL，接口失败自动切换备用地址
- 🔄 **定时自动刷新**：可配置IP刷新时间间隔，配置保存在本地`config.ini`
- 🖱️ **托盘后台驻留**
  - 双击托盘图标：快速切换悬浮窗显示/隐藏
  - 托盘右键菜单：显示/隐藏悬浮窗、**手动刷新IP**、开机自启、配置、关于、退出
- ⚙️ **设置对话框**：可视化增删编辑公网IP接口URL列表，保存到配置文件
- 🚀 **Windows开机自启**
  - 操作`HKEY_CURRENT_USER`注册表，**无需管理员权限**
  - 路径空格自动添加英文双引号，解决Windows Run项启动失败问题
  - 路径校验：程序移动目录会识别旧注册表失效，避免假勾选现象
- 📝 **本地日志系统**
  - 同时输出控制台 + 本地日志文件 `ipoverlay.log`
  - 日志自动轮转，单文件最大2MB，旧日志备份为 `ipoverlay.old.log`
  - 记录配置读写、注册表操作、网络请求、异常警告，方便问题排查

## 📋 环境要求
- Windows 10 / Windows 11
- Qt5.15+ / Qt6，依赖 `Widgets`、`Network` 模块
- MSVC / MinGW C++编译器，C++17
